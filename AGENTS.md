# slicc-cli

`slicc`: one Go binary (macOS, Windows, Linux; `CGO_ENABLED=0`) that links a machine to seven over WebRTC (pion). The setup goes over CDP or loopback HTTP (`slicc open`) locally, or through the tray hub's join URL remotely. Capabilities on the link: net, http, ssh, cdp, kernel-in, fs. The link protocol is specified in README.md and must stay in step with seven's link exit (slicc-bios). No comments in any file except Go directives. Agent guidance lives only in this AGENTS.md (≤1000 characters). Do not add CLAUDE.md. Unit tests (`*_test.go` next to the code) are gitignored; `test/integration/` is committed; CI (`ci.yml`, the shared pipeline) tests Linux. `npm run lint` runs the slicc lint tools, gofmt, tidy, vet and golangci-lint. Telemetry is `github.com/ai-ecoverse/go-optel`. Releases come from `main` via semantic-release. Never move or delete a pushed tag (Go's checksum DB pins it); retract bad versions in go.mod and release anew. v2+ needs a `/vN` module path first.
